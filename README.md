ESP32‐C3を使ったBluetooth（BLE）接続のレースシミュレーター用ボタン付きステアリングのためのファームウェアです。<br>SimhubでLED制御ができます。

# ざっくり使い方
## 用意するもの
* XIAO ESP32‐C3
    * 他のマイコンなら`platformio.ini`を適宜修正してください（ソースも修正がいるかも）
* PlatformIO (VSCode)
* ws2812b (シリアルLED 5V駆動の物)：20個までは行ける もっと増やすことも可
* モーメンタリースイッチ（押してる間だけONになるタイプのスイッチ）：最大9個
    * 同じ数のダイオードがあった方が良いです
* ロータリーエンコーダー：最大2個
* Simagic製か互換性のあるQR
* それらをいい感じに収められるハウジング

## 書き込み
0. PlatformIOとESP32‐C3を使えるようにしておいてください
1. 最新のリリースのZIPファイルをDLして適当な場所に展開してください
2. PlatformIOで展開したファイルを開いてください
    * PlatformIOのプロジェクトとして読み込まれるのを少し待ってください 
3. ビルドする前にライブラリに一部修正が必要です。
    1. 2番の手順が正しく完了していればこのファイルがあるはず(エラーになっていると思われる)
        ```.pio\libdeps\seeed_xiao_esp32c3\ESP32-BLE-Gamepad\BleNUS.cpp```
    2. 1行目に `#include <Arduino.h>` を追加します
    3. そのまま保存してください
4. 3の修正ができたらビルド→書き込みをします
5. このリポジトリとしてはここで完成です

## 組み立て
* 回路図はまだありません('ω')
* QRの電源は上限5vになるようにESP32C3へ接続します
    * 裏のバッテリー端子から入れるといいです
    * ただし逆流するので瘢痕につないだままUSB接続しないこと（ダイオード入れとくといいかも）
* D0はLEDのデータ出力ピンです
    * ws2812bのDataInを接続します
    * 電源はQRの電源端子からとります（ESP32の電源だと降圧されてしまいます）
* D1～D6はボタンマトリックス用のピンです
    * D1～3がアウトプットでマイナス側です
    * D4～6がインプットでプラス側です
    * 各スイッチはインプットピンースイッチーダイオードーアウトプットピンと接続します
    * これでマトリックスを組んでください（まるなげ）
    * ロータリーエンコーダーのプッシュボタンやホーンボタンもここに含めてください
* D7～10はロータリーエンコーダー用のピンです
    * D7、D8にエンコーダー１のA相B相を配線します
    * D9、D10にエンコーダー２のA相B相を配線します
    * 書いている時点で方向を忘れてしまっているので、テストして好みの方向になるようにしてください（まるなげ）
* アンテナはなくても動きますが、あった方が無難です
    * ついでに外に出るようにするとなお安定するはずです
* 出来上がったものをいい感じにハウジングとQRに収めてください
* ステアリングまで取り付けたら完成です

## 接続

### BLE接続
1. QRをハンコンベースに接続すると電源が入るはずです（LEDがすべて赤色に点灯するはずです）
2. PCの設定からBluetoothデバイスを探し`BLE_Wheel`を見つけてペアリングしてください
    * この時点でスイッチとロータリーエンコーダーが使えるはずです

### Simhub接続
1. 同梱しているデバイス定義をSimhubにインポートします
    1. Simhubを立ち上げ、Devicesの右上`Utilities`から`Device definition projects`を開きます
    2. 左下の`Import`より、最初に展開したZIPファイルに同梱の`simhub/BLE-SimhubSteering.shdd`を指定して開いてください
    3. LEDの数やHIDレポートサイズを変更した人は`Edit`から`Hardware communication`を変更してください（特にソースコードをいじっていない人はこの手順を飛ばせます）
        * 変更が終わったら下の`Save definition`を押してウインドウを閉じられます
    4. `+Instantiate` を押します
2. 1の手順を終えていればLEDの制御設定画面が見えているはずです
3. 後は好きなようにLEDを設定してください `Edit Profile` から設定できます
    * 一応プロファイルを同梱しておきます `Any Game - Default Profile.ledsprofile` `Import profile` から読み込んでください
